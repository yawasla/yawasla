# Asma

Example extension: one of the names of Allah each day, in a dashboard panel.

## Source

- Arabic text copied verbatim from Jami at-Tirmidhi, hadith 3507, [hadith-api](https://github.com/fawazahmed0/hadith-api) edition `ara-tirmidhi` (public domain, Unlicense)
- "Allah" first, then the 98 names listed in the hadith: 99 names
- Grade given by the source: daif (Ahmad Shakir, Al-Albani, Zubair Ali Zai). The number of 99 names is authentic (Bukhari, Muslim); the list is the one commonly known and recited. Shown: the names, and at the bottom of the panel "List reported by at-Tirmidhi (no. 3507)", never the hadith itself nor as evidence
- Transliteration written by Yawasla, simplified on purpose (no long vowels or dots)

## Name of the day

Days elapsed since 1 Muharram 1 AH (19 July 622, proleptic Gregorian), modulo 99, in the PHP default timezone: the same name for every site on the same day, in the order of the list.
